Integrantes: Emanuelle Santos Gonçalves, Laura Maria dos Santos Pereira, Luiza Mendes Barros Amaral, Tomás Freitas Hallack

Pequenas e médias floriculturas costumam ter dificuldades para vender online e organizar suas vendas, dependendo muito do atendimento presencial ou de mensagens
informais. Isso dificulta a exibição do catálogo de produtos, a montagem de arranjos e o controle de estoque e pedidos em tempo real.

O objetivo deste projeto é desenvolver um sistema para uma floricultura virtual que automatize o processo de vendas. O sistema permitirá que os clientes naveguem
pelo catálogo, façam pedidos e personalizem os destinatários de forma simples, além de oferecer um painel administrativo para controle de estoque e usuários.

A motivação para a escolha surgiu a partir de um trabalho prévio de planejamento de marketing que um dos integrantes realizou sobre o mercado de flores online para
presentear. Durante a pesquisa, houve grande dificuldade em encontrar informações transparentes e plataformas bem estruturadas nesse segmento. Essa falta de dados
e de soluções acessíveis no mercado motivou o grupo a desenvolver um sistema funcional focado nesse modelo de negócio, unindo o e-commerce tradicional à venda online
para presente.
