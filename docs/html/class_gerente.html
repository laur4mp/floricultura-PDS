Detailed Description

Pessoa com permissão para administrar produtos, estoque, vendas e cupons.

Herda de Pessoa e concentra as operações de gestão da loja: cadastro e edição de produtos, controle de estoque, atualização de status de vendas e pagamentos, e criação/aplicação de cupons de desconto.
