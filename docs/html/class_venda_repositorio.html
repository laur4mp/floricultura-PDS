Detailed Description

Lê e grava a lista de vendas em um arquivo TXT.

Campos separados por '|'. Cada item de uma venda ocupa uma linha "I" e vem ANTES da linha "V" da própria venda:

I|idProd|nome|descricao|categoria|preco|imagem|estoque|minimo|qtd V|id|idPessoa|destinatario|statusVenda|statusPagamento|data|horario
