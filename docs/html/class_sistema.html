Detailed Description

Central de dados da floricultura.

Os usuarios sao guardados como ponteiros (Pessoa*) para preservar o tipo real de cada um (Gerente ou Comprador). O Sistema eh o dono desses objetos e os apaga no destrutor.

◆ finalizarPedido()

Venda Sistema::finalizarPedido ( Comprador & comprador,
const Endereco & endereco,
const Desconto * cupom )

Processa e finaliza uma compra realizada por um comprador.

Valida o carrinho e o endereço de entrega, garante a disponibilidade de estoque de cada item, dá baixa no estoque dos produtos, calcula previsões de entrega, aplica o cupom, se válido e registra a venda.

Parameters
compradorInstância do Comprador que está realizando o pedido.
enderecoEndereço selecionado para a entrega.
cupomCupom de desconto aplicado (se for válido).
Returns
A Venda gerada e registrada no sistema.
Exceptions
std::invalid_argumentse o carrinho estiver vazio ou o destinatário do endereço não estiver informado.
std::runtime_errorse algum produto do carrinho não for encontrado ou se houver estoque insuficiente.
