\doxysubsection{Detailed Description}
Central de dados da floricultura. 

Os usuarios sao guardados como ponteiros (Pessoa\texorpdfstring{$\ast$}{*}) para preservar o tipo real de cada um (\doxylink{class_gerente}{Gerente} ou \doxylink{class_comprador}{Comprador}). O \doxylink{class_sistema}{Sistema} eh o dono desses objetos e os apaga no destrutor.
