\doxysubsection{Detailed Description}
Representa um comprador do sistema. 

Classe derivada de \doxylink{class_pessoa}{Pessoa} que representa um usuário capaz de pesquisar e favroitar produtos, realizar pedidos, acompanhar suas compras e consultar seu historico de pedidos.
